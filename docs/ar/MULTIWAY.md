# Multi-Way & Smart Groups

هذا القسم يحتوي محرك Eshtaya Multi-Way Control كاملًا داخل المنصة الجديدة.

## Multi-Way

يمكن ربط Output فعلي مع عدد غير محدود من Controllers برمجيًا. يدعم Mirror وToggle وMomentary وEvent وFollow Output، مع معالجة الضغطات السريعة بالترتيب وحماية Cloud Echo وإعادة مطابقة الحالة النهائية للمصدر.

## Smart Groups

يدعم المجموعات Native حسب Domain، سواء Virtual Group أو Physical Controller Group، مع التحقق من التوافق والصحة وإعادة المحاولة المحدودة.

## Action Groups

يجمع Scenes وScripts وAutomations داخل زر Run فعلي، مع Parallel/Sequential وسياسات فشل وخيارات Automation conditions.

## Commissioning والصحة

يشمل Learn Mode، Area-aware setup، Templates، Clone، الاختبار الكامل، Missing Entity Repair، Quality/Latency، Backup/Restore، Undo وConfiguration Lock.
