# الهجرة من الإضافات السابقة

## القاعدة الأساسية

لا تشغّل المحرك القديم والجديد على نفس Multi-Way groups في نفس الوقت.

## Entity Manager

إذا كان Storage الجديد فارغًا يستطيع قسم Entity Control استيراد Storage الإضافة السابقة. كما تبقى ملفات `hidden_entities.yaml` و`alexa_rules.json` طرقًا آمنة للنقل.

## Multi-Way

صدّر Full Backup من الإضافة القديمة، ثم استورده في Multi-Way المدمج. اختبر الكيانات والمجموعات والأوتوميشنز قبل تعطيل الإضافة القديمة.

لا يتم الاستحواذ التلقائي على Entity IDs القديمة أثناء وجود المحرك القديم لأن ذلك قد يسبب تكرارًا أو كيانات unavailable.
