# التحكم متعدد النقاط (Multi-Way)

## الهدف
إنشاء تحكم 2-Way و3-Way وN-Way برمجياً حول خرج فعلي وعدة أزرار/كيانات تحكم في Home Assistant، مع منطق موثوق للضغطات السريعة والتكاملات السحابية.

## تركيب المجموعة
خرج فعلي، Controllers، نوع كيان افتراضي، وسلوك. لكل Controller وضع تشغيل وعكس واختيار انعكاس الحالة.

## أوضاع التحكم
- مطابقة: حالة الزر تطلب نفس حالة الخرج.
- تبديل: الحدث يقلب الحالة.
- تشغيل لحظي: الحدث يطلب تشغيل.
- إيقاف لحظي: الحدث يطلب إيقاف.
- حدث: مناسب للأزرار والـEvents.
- متابعة الخرج: يجعل Controller يتبع الحالة المرجعية.

## أنماط الأداء
فوري لأقل تأخير محسوس، متوازن للجمع بين السرعة والتأكيد، وآمن لزيادة التحقق مع الأجهزة البطيئة/غير الموثوقة.

## المرجعية والضغطات السريعة
المحرك يرتب الأحداث بالتسلسل، يحمي من Cloud Echo المتأخر ويعمل Settling نهائي حتى لا تغلب Update قديمة على آخر ضغطة حقيقية.

## التأكيد وإعادة المحاولة
Timeout وConfirm Output وMax Retries يمكن ضبطها عالمياً أو ضمن سلوك المجموعة. إعادة المحاولة محدودة حتى لا يحارب النظام جهازاً مفصولاً بلا نهاية.

## الصحة
سليم، معطل، خرج مفقود، خرج Offline، غير متزامن أو قيد الاسترجاع. Diagnostics تبين المصدر والـLatency والأعضاء والأخطاء.

## خطوات الإنشاء
حدد الخرج، أضف الأزرار، اختر أوضاعها، اختر الأداء، راجع التأكيد، احفظ، اختبر الكيان الافتراضي، اختبر كل زر، اعمل Rapid Toggle عند الحاجة، وتأكد أن الصحة تعود سليمة.

## الأمان
لا تستخدم نفس الخرج أو Controller في مجموعات متعارضة. عند تغير Entity ID استخدم Repair/Remap بدلاً من إعادة بناء المجموعة عشوائياً.

## النسخ الاحتياطي
قبل تعديل واسع صدّر Full Backup. Snapshots وUndo للتغييرات المدعومة، والـFull Restore للاسترجاع الكامل.
